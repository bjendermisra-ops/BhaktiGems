# Vrindavan Adventure 3D — Forest Trail

One playable WebGL level, separate from the classic game. Three.js 0.160.1 (pinned CDN), procedural 3D environment and articulated character, checkpoint, collectibles, two calf seva tasks, touch/keyboard controls, pause and replay. Online connection required to fetch engine on initial load. No account. This is a quality-evaluation vertical slice, not the complete 12-level release.
